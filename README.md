# RDAYNT Games

Sitio web de **RDAYNT Games**, estudio de videojuegos de la República Dominicana
(RD = República Dominicana, A = Ángel, Y = Yeychol, NT = Navarrete).

- `index.html`: el inicio del estudio.
- `dale-concho-rd/`: la página de Dale Concho RD y su `privacidad.html` (la política de privacidad que va en Google Play).
- `img/`: las imágenes (cada juego en su carpeta).
- `estilos.css`: el diseño de todas las páginas.

Se publica con GitHub Pages. Para un juego nuevo: su carpeta (`nombre-del-juego/` con `index.html` y
`privacidad.html`), sus imágenes en `img/nombre-del-juego/` y su tarjeta en "Nuestros juegos" del inicio.
